## Sources
The RDH retrieved 2024 general election precinct-level results from the Georgia Secretary of State [website] (https://results.sos.ga.gov/results/public/Georgia/elections/2024NovGen). The RDH navigated to each county's election results page and download the xlsx file. For each county, the xlsx file contains 3 separate spreadsheets: "Total Votes", "Total Votes by Group" and "Precinct Results". The RDH concatenated precinct results for all 159 counties together.

Precinct shapefiles sourced primarily from the Office of Reapportionment in the Georgia General Assembly (https://www.legis.ga.gov/api/document/docs/default-source/reapportionment-document-library/precincts/gaprec_2024-website-shapefile.zip?sfvrsn=7b38ca99_2). As noted on the file documentation: "This file is a best fit version of the maps provided by county election offices, created using current census geography of that decade.  Please contact the specific county or their webpage if you need an official version of their precinct lines." In order to join the file to election results and ensure boundaries were updated and match those used in the November election, a number of counties throughout the state were contacted. A handful of counties provided street reports, which are tabular datasets that relate particular address ranges to particular precincts. All counties were compared against a Georgia voter file from L2 dated December 24th, 2024. Ultimately, the counties were sourced as such:

## Notes on Field Names (adapted from VEST):
Columns reporting votes generally follow the pattern:
One example is:
GPREDCLI
The first character is G for a general election, P for a primary, S for a special, and R for a runoff.
Characters 2 and 3 are the year of the election.
Characters 4-6 represent the office type (see list below).
Character 7 represents the party of the candidate.
Characters 8-10 are the first three letters of the candidate's last name.

Office Codes Used:
A# - Constitutional Amendment
RF# - Statewide Referendum
PRE - President of the US
CON## - U.S. Congress
SU## - State Legislative Upper
SL### - State Legislative Lower

Party Codes Used:
D - Democratic
G - Green
I - Independent
L - Libertarian Party
R - Republican

## Processing Steps
Visit the RDH GitHub and the processing script for this code [here](https://github.com/nonpartisan-redistricting-datahub/pber_collection)

One precinct, CHEROKEE-:-269-WALESKA, appeared in the election results but did not contain any votes and did not appear in county precinct lists. This precinct has been removed from the file.

After joining the precincts to their boundaries, the files were checked for precinct-district splits. Ultimately, the precinct boundary and election result files are split across four different files. The "_all_" file contains all the election results joined to precinct boundaries, but does not account for the various precinct-district splits identified in processing and as such, does not contain district assignments. The "_cong_", "_sldl_", and "_sldu_" files contain Congressional, State House and State Senate results at the most granular units for which data is available. Please note that in order to minimize superfluous splits, precinct splits are only made when a precinct contains votes for candidates in multiple districts, as such district assignments for precincts many not perfectly correspond to the districts themselves, particularly in large, uninhabited areas.

In a handful of cases, votes appear in Legislative District contests in which no portion of the precinct is contained within the district. This occurred in 6 precincts across 5 different legislative districts. As a result of this issue, these votes are removed from the split, "_sldl_" file and the totals will not exactly match. These differences include: 1 vote for GSL162DGIL in CHATHAM-:-8-10C, 8 votes for GSL041DSMI and 2 votes for GSL041RSMI in COBB-:-POWDER SPRINGS 2A, 3 votes for GSL176RBUR in each of COFFEE-:-BROXTON and COFFEE-:-WEST GREEN, 29 votes for GSL118DBEL and 2 votes for GSL118RCRO in NEWTON-:-20-STANSELLS and lastly, 1 vote for GSL147RBAL in PEACH-:-FORT VALLEY 1. None of these votes are not removed from the "_all_" file.

Lastly, the maup smart_repair function was run in order to clean the small overlaps and geographical gaps that occur from combining shapefiles from a number of different sources.
